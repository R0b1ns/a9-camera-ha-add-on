New camera in its own access point (AP mode)

Checking Home Assistant's Wi-Fi…

Requires LAN: Home Assistant must be connected by cable and its Wi-Fi must be unused. HA joins the camera's NAXCLOW network with its Wi-Fi, sends the new credentials and disconnects again. HA stays reachable over LAN the whole time. If Wi-Fi is already in use, use the downloadable helper below.

Home Assistant has no Wi-Fi? Use the local helper

Download the standalone script, put it on a Mac, Windows or Linux computer and join the camera's NAXCLOW Wi-Fi with that computer. Then run the script: it waits for the camera, asks for the new network and configures it. No parameters, no Python installation.

macOS / Linux (Python 3 script) · Windows (.bat) · macOS (.command)

How it works

  1. This page is only for new cameras that are not connected yet and broadcast their own NAXCLOW access point. Open it from the A9 Camera add-on panel in Home Assistant; a login is required.
  2. Home Assistant must be on LAN with its Wi-Fi unused. Scan for access points, select the camera AP, enter its password (usually 34974033A) and the new network. Use a 2.4 GHz network – these cameras do not support 5 GHz.
  3. Home Assistant briefly joins the camera AP, sends the credentials and disconnects again. It stays reachable over LAN throughout.
  4. Keep the DNS rewrites *.naxclow.com and *.naxclow.com.cn pointing at the Home Assistant host in the new network's DHCP DNS. Otherwise the camera will call the original cloud again.

For a camera that is already connected, use the Change Wi-Fi form directly on its card on the camera overview page. That sends the change over the existing connection; it does not need AP mode.
