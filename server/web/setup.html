A9 Camera – Wi-Fi setup

How it works

  1. Open this page from the A9 Camera add-on panel in Home Assistant. The page is only reachable when you are logged in to Home Assistant.
  2. Make sure the camera appears in the list above. The change is sent over its existing connection, so the camera must be online. If it is not online, power-cycle it and wait a few minutes until it reconnects.
  3. Enter the name and password of the new network and press Change Wi-Fi. Use a 2.4 GHz network – these cameras do not support 5 GHz.
  4. The camera applies the change immediately and reboots. It disappears from the list for a minute or two and then comes back on the new network.
  5. Keep the DNS rewrites *.naxclow.com and *.naxclow.com.cn pointing at the Home Assistant host in the new network's DHCP DNS as well. Otherwise the camera will call the original cloud again.

If the camera has never joined a Wi-Fi network (it is in its own NAXCLOW access point mode), this page cannot reach it yet. Connect it to any network once with the V720 app or the AP-mode setup script, then use this page to move it.
